Archivo de documentacion principal Estrategia GitOps

#Funciones Principales:
Bootstrap de un clúster desde cero.
Incorporación de una aplicación nueva sin modificar la infraestructura.
Promoción controlada de dev a staging y producción.
Reversión de una versión mediante git revert.
Bloqueo de una imagen que incumpla las políticas.
Separación de permisos entre equipos.
Recuperación después de eliminar un recurso gestionado por Flux.
Validación automática de manifiestos antes de aceptar un Pull Request.
